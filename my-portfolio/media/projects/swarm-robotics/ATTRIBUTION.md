# HERO Common — Swarm Robotics Media Attribution

The assets in this directory are sourced from the open-source HeRo Common project developed by VeRLab (Laboratório de Visão Computacional e Robótica) at Universidade Federal de Minas Gerais (UFMG).

- **Project:** HERO Common — Swarm Robotics Framework & Experimental Platform
- **Source Website:** https://verlab.github.io/hero_common/
- **Repository:** https://github.com/verlab/hero_common
- **Authors/Maintainers:** VeRLab / UFMG Robotics Group

### Assets Included:
1. `hero_swarm_test.png`: Physical HeRo v2.5 micro-robots in formation (Source: VeRLab / hero_common)
2. `hero_gazebo_swarm.png`: 16-agent distributed swarm simulation in Gazebo with ROS topic visualization (Source: VeRLab / hero_common)
3. `hero_pcb.png`: White octagonal modular PCB architecture for HeRo swarm robot (Source: VeRLab / hero_common)
4. `hero_robot_single.jpg`: Individual HeRo robot with optical ArUco navigation top hat (Source: VeRLab / hero_common)

*Used for research, learning, educational reference, and platform architecture study with clear attribution.*
