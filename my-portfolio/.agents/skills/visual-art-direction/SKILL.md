# Visual Art Direction Skill

## Purpose

Evaluate and direct the visual composition, palette, typography, geometry,
materiality, and atmosphere of the portfolio. The portfolio should feel
like a carefully art-directed robotics engineering publication/product —
not a template.

---

## Evaluation Dimensions

### Composition
- Intentional asymmetry vs. purposeful symmetry
- Visual anchors that guide the eye
- Rule of thirds / golden ratio awareness
- Focal points deliberate, not accidental
- Balance without symmetry

### Palette
- Minimal, intentional color system
- Every color has a defined role
- Semantic meaning (not decorative)
- Works in dark/light if applicable
- Accessible contrast ratios

### Typography
- Type as structure, not decoration
- Scale serves hierarchy
- Font choice communicates identity
- Readable at all sizes
- Technical/mono where appropriate

### Photography / Imagery
- Real project imagery over stock
- Technical photography: hardware, lab, robots
- Consistent treatment (crop, tone, aspect)
- Images as evidence, not decoration
- Alt text for every image

### Illustration / Diagrams
- Technical accuracy
- Consistent line weight, style
- Purposeful color coding
- Labels integrated, not floating
- SVG for scalability

### Geometry
- Shapes have meaning
- Squircle radii system (not random rounding)
- Grid alignment
- Proportional relationships

### Texture / Materiality
- Subtle surface qualities
- Glass/frosted glass with purpose
- Paper-like backgrounds
- Depth through shadow, not texture noise

### Negative Space
- Active whitespace (structures content)
- Not empty space
- Breathing room proportional to density
- Macro and micro whitespace

### Visual Density
- Appropriate for content type
- Hero: lower density, high impact
- Project detail: higher density, scannable
- Skills: modular, comparable
- Rhythm of dense/quiet

### Atmosphere
- Professional, not sterile
- Technical, not cold
- Precise, not rigid
- Curious, not chaotic
- Memorable identity

---

## Robotics Engineering Visual Language

The design should communicate:

| Quality | Visual Expression |
|---------|-------------------|
| Precision | Sharp alignments, exact spacing, deliberate typography |
| Engineering | Structural layouts, technical diagrams, evidence |
| Research | Exploratory sections, work-in-progress honesty |
| Curiosity | Reveals on interaction, deeper layers available |
| Systems Thinking | Connected components, spatial continuity |
| Technical Depth | Monospace for specs, real data, no hand-waving |
| Experimentation | Iteration visible, failures acknowledged |

---

## What NOT to Do

- **Stereotypical robotics HUD**: fake telemetry, scanning lines, military UI
- **Cyberpunk aesthetic**: neon glows, dark mode forced, "hacker" vibe
- **Gaming dashboard**: health bars, XP, achievement popups
- **SaaS landing page**: hero + 3-column features + testimonials + footer
- **Generic "AI" look**: purple gradients, floating orbs, neural network diagrams
- **Over-engineered control panel**: knobs, dials, gauges for non-control content

---

## Art Direction Process

For any visual decision:

1. **Reference the system** — Does it use existing tokens?
2. **Check hierarchy** — Does it reinforce or confuse?
3. **Verify intent** — Is there a design reason?
4. **Test coherence** — Does it belong on the same page?
5. **Evaluate restraint** — Is it the minimum effective dose?
6. **Consider atmosphere** — Does it support the identity?

---

## Final Authority

Visual Art Direction owns:
- Color system
- Typography scale
- Spacing scale
- Shadow/elevation system
- Border/radius system
- Image treatment
- Diagram style
- Overall visual coherence

Conflicts with other skills → Visual Art Direction + Design Director resolve.
